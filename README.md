# hack-2cc01208-anomaly-detected

Команда **Anomaly Detected** · HackAlem AI · Track 06 Creative Industries · кейс «Smart contractor matching» (Firebird).

Пользователь вводит параметры заказа (город, дата, тип события, категория, бюджет, часы, язык)
и получает до 3 подрядчиков с конкретным объяснением, почему каждый подходит.

## Структура

```
backend/   — API подбора (Python)
frontend/  — index.html + app.js + style.css, без сборки
data/      — hackathon-dataset-anonymized.jsonl
docs/      — api.md (контракт между фронтом и бэком)
```

### Frontend

Без сборки и зависимостей: чистый HTML + JS.

- Вариант 1: открыть `frontend/index.html` в браузере.
- Вариант 2: `cd frontend && python -m http.server 5500`, затем открыть http://localhost:5500

Фронт обращается к бэкенду на `http://localhost:8000` (другой адрес можно задать так: `index.html?api=http://host:port`).
Бэкенд должен разрешать CORS для `http://localhost:5500` и для `null` (страница, открытая как файл).

Без бэкенда: включите галочку «Демо-режим» вверху справа. Ответы берутся из `frontend/mock.js`.

Кнопки «Демо-запросы» подставляют проверочные запросы: плотная категория, редкая категория,
тот же запрос в декабре, «кандидаты есть, но не подходят» и «категории нет в городе».
Кнопка «Сравнить с другой датой» показывает два результата рядом: видно, что выдача меняется из-за занятости.
